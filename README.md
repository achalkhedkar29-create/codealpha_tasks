# Image Gallery

A responsive and interactive **Image Gallery** created using HTML, CSS, and JavaScript. The project displays images in a clean grid layout and includes a search feature to help users find images easily.

## Features

* Responsive image grid
* Search functionality
* Clean and simple design
* Multiple images displayed in an organized layout
* Easy navigation and viewing

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the Image Gallery project folder.
3. Make sure the `images` folder contains the required images.
4. Open `index.html` in a web browser.
5. Browse and search through the gallery.

## Project Purpose

This project was created to practice front-end web development concepts such as HTML structure, CSS Grid, image handling, and JavaScript-based search functionality.
